HOW TO RUN
1. Extract the ZIP.
2. Open index.html in Chrome, Edge or Firefox.
3. The website works without a server or database.

IMPORTANT ABOUT THE 5000+ QUESTION BANK
The project contains a JavaScript question-bank generator that creates 6000 questions from IT topic concepts and multiple academically relevant question formats. This keeps the download small while still giving the website a 5000+ question bank. For a university submission that requires a manually authored question bank, the generator can later be replaced with a JSON/database containing individually reviewed questions.

HOW TO GET A PUBLIC WEBSITE LINK
OPTION 1 — GITHUB PAGES (FREE)
1. Create a GitHub account.
2. Create a repository, e.g. it-quiz.
3. Upload index.html, style.css and script.js.
4. Open Settings -> Pages.
5. Choose Deploy from a branch -> main -> /(root).
6. Save.
7. GitHub provides a link similar to:
   https://YOUR-USERNAME.github.io/it-quiz/

OPTION 2 — NETLIFY
1. Create a Netlify account.
2. Upload the extracted website folder as a new site.
3. Netlify provides a public link.

NOTE
This is a front-end academic project. Scores exist in the browser and are not saved to an online database. A future version can add Firebase/Supabase/Node.js/PHP + MySQL for persistent student accounts and results.
